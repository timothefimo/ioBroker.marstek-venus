Verbindung / Connection
Leer lassen für automatische Erkennung per UDP-Broadcast im Netzwerk
Standard: 30000 – wie in der Marstek App unter Local API eingestellt
Abfrage / Polling
Wie oft werden die Werte vom Gerät gelesen? Minimum: 5 Sekunden
Standard-Dauer beim Aktivieren des Passivmodus über control.setPassivePower
Voraussetzung: Bitte aktiviere die Local API in der Marstek App unter Einstellungen → Local API (App-Version ≥ 1.6.51). Notiere den dort angezeigten UDP-Port. Das Gerät muss im selben Netzwerk wie ioBroker erreichbar sein.

Hinweis: Nach dem Speichern wird die Instanz automatisch neu gestartet damit die Einstellungen übernommen werden.
